# 🔑 Modern Login Form UI

Um projeto simples e responsivo de **Formulário de Login Moderno**, desenvolvido para praticar conceitos de **HTML5** e **CSS3**, com foco em design elegante, experiência do usuário e validação de formulários.

---

## 📸 Preview do Projeto

Interface contendo:

- Campo de e-mail
- Campo de senha
- Opção "Lembre de mim"
- Link para recuperação de senha
- Botão de login
- Link para criação de conta
- Validação nativa dos campos

---

## ✨ Tecnologias Utilizadas

- **HTML5**
- **CSS3**

---

## 🎨 Características do Design

- Visual moderno e minimalista
- Gradiente em tons de roxo
- Campos com bordas arredondadas
- Layout centralizado
- Interface intuitiva e amigável
- Design responsivo para diferentes dispositivos

---

## 🚀 Objetivo do Projeto

Praticar habilidades de desenvolvimento front-end através da criação de uma interface de autenticação moderna, explorando conceitos de formulários, validação HTML, estilização avançada e responsividade.

---

## 📚 Funcionalidades

- Login com e-mail e senha
- Validação automática do campo de e-mail
- Opção para manter o usuário conectado
- Recuperação de senha
- Redirecionamento para cadastro de novos usuários
